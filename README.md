# xbot-approve

投稿候補の承認画面（1ページの静的サイト）。GitHub Pages で配信しています。

## これは写しです

**ここを直さないでください。**正本は別のリポジトリにあり、
`web/approve/index.html` を直すと自動でここへ同期されます。

## 何をする画面か

bot が作った投稿候補に、○（そのまま出す）／△（直して出す）／×（出さない）
を付けるだけの画面です。押さなければ何も出ません。

## つなぎ先

初回に Supabase の URL と publishable キーを1度だけ入れます。
**入れた値はブラウザの localStorage に入り、このリポジトリには残りません。**
secret キーは入れないでください（画面側で弾いています）。

読み書きできるのは自分の行だけです（RLS）。
